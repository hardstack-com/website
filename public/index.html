What the subscription includes

A full workbench, exposed as an API.

Every HardStack plan is a physical bench racked in our lab, wired to your hardware and reachable over the network. Nothing is simulated — you are driving real instruments against real silicon.

  • CAM 1

    Live bench video

    Low-latency streams of the board, the instrument faces and the actuators, so you can see exactly what your code is doing to the hardware.

  • PROG

    Firmware flashing

    Push a build and flash the target over SWD, JTAG, UART or DFU. Power-cycle, halt and recover bricked parts without touching the bench.

  • INST

    Instrument orchestration

    Scope, logic analyser, function generator, programmable supply and DMM, all scriptable in one session with synchronised capture.

  • ACT

    Robotic actuators

    Press buttons, throw switches, seat connectors and reposition probes under program control, so physical interaction is part of the test.

  • API

    Web app and REST API

    Operate a bench by hand in the browser, or call the same capabilities from your test suite, your CI pipeline or a scheduled job.

  • AGT

    Built for AI agents

    An agent-native tool interface lets autonomous agents run bring-up, bisect a hardware regression and report back without a human in the loop.
